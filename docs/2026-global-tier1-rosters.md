# 2026 시즌 전체 1부 리그 · 26 기본 카드 로스터

이 파일은 **2026 월즈 19팀만이 아니라, 2026 시즌 전체 1부 대회 참가 60팀**을 다룹니다. 국내/중국/유럽/북미/브라질/태평양 모두 포함합니다. 기준일은 **2026-11-06**이며 1팀당 주전 5명씩 우선 등록합니다. 선수 영입·교체와 교체 선수/서브 명단은 추가 검증 대상입니다.

- **26**: 모든 1부 리그 선수
- **26WR**: 월즈 플레이인·스위스 참가, 8강 미진출 선수
- **26WRs**: 월즈 8강 진출 선수

선수 사진: `frontend/public/players/26_<선수명>.png`; 팀 로고: `frontend/public/teams/<팀코드>.png`. 월즈 카드 사진은 `26WR_<선수명>.png` 또는 `26WRs_<선수명>.png`를 사용합니다. 이미 등록한 19팀 월즈 카드/OVR/유저 보유 카드는 이 마이그레이션에서 변경하지 않습니다.

**주의:** 새로 추가한 월즈 미진출 선수 OVR은 임시 게임 밸런스 값이며 실적 기반 공식 평점이 아닙니다. 또한 LEC Versus에는 초청팀 2팀(LR/KCB)이 포함되어 있으며, LPL Split 1의 OMG와 UP도 2026 시즌 참가 기록에 포함했습니다.

### DB 적용 (기존 2026 월즈 마이그레이션 완료 후)

```bash
mysql -u root -p lol_card_game < database/migrations/2026_global_tier1_live.sql
```

위 쿼리는 동일한 선수/팀/포지션의 26 LIVE가 이미 있으면 새로 만들지 않습니다. 기존 월즈 전용 26WR/26WRs 카드는 유지합니다. 국적은 리그가 아닌 실제 선수 국적을 입력해야 하며, 미확인 국적은 운영자 페이지에서 등록합니다.

### 확인용 SQL

```sql
SELECT region,COUNT(DISTINCT team) AS team_count,COUNT(*) AS total_live_cards
FROM players WHERE season='26 LIVE' GROUP BY region;
```
